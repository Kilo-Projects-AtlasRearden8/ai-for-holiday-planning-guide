# STATUS

## What was built

A beginner manual on using AI for the holidays, delivered as Markdown docs in `docs/` and a static HTML site in `site/`. Kind, low-stress approach — plain English, step by step, never condescending. Created by Dylan Asdale of Asdale Dynamics, LLC.

Topics covered:

- Getting started with AI tools — free chat tools, your first prompt, privacy reminders, low-stress ground rules
- Gift ideas and budgets — gift lists, budgets, brainstorming prompts, low-cost gifts, spending tracker
- Travel plans — itineraries, packing lists, travel budgets, disrupted plans, safety and privacy
- Gathering checklists — guest list and RSVPs, prep timeline, day-of run sheet, low-energy hosting, cleanup
- Meal plans — ingredients on hand, meal planning, grocery lists, cooking timeline, dietary needs, leftovers
- Post-holiday decluttering — one small area at a time, four piles (keep/donate/recycle/trash), gifts, food, decorations, ADHD-friendly tips
- Copy-and-paste AI prompts — ready-to-use prompt templates for every section
- Printable planners — Gift Budget Planner, Travel Planner, Gathering Planner, Meal Planner, Decluttering Planner

Additional features:

- "Welcome" guided reading path on the index page
- Print styles (`@media print`) so planner pages print cleanly without nav/header/footer
- Dependency-free static site builder (`build.js`) with no external packages — `site/` is generated from `docs/`
- Every HTML page credits Asdale Dynamics, LLC and carries the copyright line
- MIT LICENSE with the exact copyright line

## How to run it

Requires Node.js.

```bash
cd /workspace/kilo-lab/ai-for-holiday-planning-guide
npm install      # optional; no production dependencies are used
npm run build    # reads docs/ Markdown, writes static HTML to site/
npm test         # verifies build output
npm run lint     # syntax-checks build.js and tests/build-test.js
```

Open `site/index.html` in a browser to read the guide. To print a planner, open the corresponding page in `site/` (e.g. `site/printable-planners.html`) and choose File > Print; print styles hide the nav, header, and footer. `site/` is generated output — do not edit it by hand.

## Known gaps

- No automated spellcheck or prose linter; copy was reviewed manually
- HTML output is generated by a dependency-free Markdown converter; complex Markdown (nested lists, footnotes) is not supported, and none is used
- No CI/CD workflows (`.github/workflows` intentionally omitted per project rules)
- No search function on the static site; navigation bar links all pages
- Travel, budget, and medical information is general education only — not professional advice
